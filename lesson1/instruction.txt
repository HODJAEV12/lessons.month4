Инструкция для создания проекта
________________________________________________
django-admin startproject <<Название>> .  Создает проект
_____________________________________________________
Cоздаем нужные папки и файлы 
templates - для html файлов
static - для параметры шаблонов
apps - для приложений
.gitignore - для игнора файлов

pip freeze > requirements.txt  - Выводит папку requirements
_________________________________________________
Заполнить файл .gitignore  - Ссылка (https://www.toptal.com/developers/gitignore) 
_________________________________________________
Настройка проека

1. settings.py  -- строка "57"- BASE_DIR / 'templates'

2. settingspy -- строка "119" - 

STATICFILES_DIRS = [BASE_DIR / 'static']

MEDIA_URL = '/media/'
MEDIA_ROOT = BASE_DIR/ 'media'

3. urls.py -- строка "18" - 

from django.conf.urls.static import static
from django.conf import settings

4. urls.py -- строка "23" - 
urlpatterns += static(settings.MEDIA_URL,document_root = settings.MEDIA_ROOT)
_________________________________________________
Создание приложение 

django-admin startapp settings  -  Создать новое приложение 

Должны зарегистрировать приложения
settings.py -- строка "33" - 

Название вашего приложения
Настроить приложение

Заходите в приложения и файле apps.py настроите 
_________________________________________________
Сделать миграцию
python manage.py makemigrations   Собирает все изменения на сайте
python3 manage.py migrate  Обновляет проект - Сохроняет изменения в базе данных
_________________________________________________
Создание супер пользователя
python manage.py createsuperuser
_________________________________________________
Запуск сайта
python manage.py runserver

Настройка всего проекта  - Settings.py
Настройка путей -  urls.py
Настройка административной панели - admin.py
Настройка приложений - apps.py
Настройка базы данных - models.py
Настройка логики сайта - views.py
